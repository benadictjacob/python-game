🐍 Hangman Game in Python
What better way to learn or brush up a programming language than by building small, fun projects?
This is a simple Python project that brings back the nostalgic Hangman game, helping you reinforce core programming concepts in an engaging way.

🎯 Purpose
This project is designed to help you:

Practice Python syntax and logic

Strengthen your understanding of fundamental programming concepts like:

Strings

Lists (arrays)

Loops and conditionals

Functions

User input and output

🕹️ About the Game
The classic Hangman game challenges the player to guess a hidden word one letter at a time. With each incorrect guess, a part of the hangman is drawn. The game ends when the word is fully guessed or the hangman is complete.
